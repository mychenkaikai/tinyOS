# x86_64 UEFI VirtualBox Smoke Test Template

Use this template for the first and every later `VirtualBox UEFI` attempt.

```text
Date:
Host machine:
VirtualBox version:
VM name:
Firmware mode:
Chipset:
Video controller:
Memory:
CPU count:
Disk image:
Image commit:
Observed result:
Reached tinyOS screen: yes/no
If no, last visible stage:
Failure bucket (V0/V1/V2/V3 or n/a):
Screenshot path:
Notes:
```

## Minimum Record Quality

Do not leave these fields blank:

- `VirtualBox version`
- `Firmware mode`
- `Disk image`
- `Image commit`
- `Observed result`
- `Reached tinyOS screen`
